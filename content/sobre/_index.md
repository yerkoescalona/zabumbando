Este site documenta padrões rítmicos do **forró nordestino** com partitura interativa e playback no navegador.

O objetivo é ser uma referência prática para músicos que estão aprendendo zabumba e pandeiro — especialmente no contexto do forró pé-de-serra.

## Como usar

Cada padrão tem:
- **Partitura interativa** gerada com [abcjs](https://www.abcjs.net/) — clique nas notas para ouvir
- **Playback com controle de andamento** — ajuste o BPM com o slider
- **Análise rítmica** explicando os elementos fundamentais

## Tecnologia

O site é gerado com [Hugo](https://gohugo.io/) e o tema [PaperMod](https://github.com/adityatelange/hugo-PaperMod). O código-fonte está disponível no [GitHub](https://github.com/yerkoescalona/zabumba).
